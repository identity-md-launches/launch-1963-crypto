# 拾账 · Crypto 个人投资账本

中文、可本地运行的投资记账应用，支持 BTC / ETH / BNB / SOL / USD 核心持仓、投资项目、法币出入金、行情和仪表盘。交付的 `dist/` 是可直接静态托管的完整应用，所有运行时资源都在本地，只有刷新行情会连接 CoinGecko。

默认打开**虚构演示账本**。点击“创建私密账本”，设置口令后从空账本开始。个人记录在当前浏览器中加密保存，刷新、关闭再打开后通过口令解锁。不同浏览器、域名、端口之间不会自动同步。

## 安装、预览和重建

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run typecheck
npm run build
npm run preview
```

浏览器打开 `http://127.0.0.1:4173/`。预览已经交付的 `dist/` 只需 `node scripts/serve.mjs`，无需安装依赖。`file://` 直接双击不支持 ES 模块和加密，请使用预览服务器。

```sh
npm test                  # 账务、CSV、加密和认证测试，自动先构建
npm run preview -- --port 4280
```

技术栈是原生 TypeScript、浏览器 ES Modules、CSS、Web Crypto API；没有运行时框架或数据库服务。唯一构建依赖 TypeScript 5.9.3 已锁定在 `package-lock.json`。构建先清理 `dist/`，再编译和复制本地资源，运行时无需 npm 或互联网（行情除外）。哈希路由和相对资源路径支持 `/preview/` 等任意静态子路径，无需服务器重写。

## 五个板块如何使用

### 1. 投资记录

新建项目，或在“记一笔”中选择“+ 新建项目”。项目支持名称、分类、账户 / 地址标签、关联项目、备注。开始日期来自第一笔流水；结束日期来自“全部结算，结束项目”那笔流水。

- **实际投入**：已经花出，扣核心余额。填写数量及当时 USD 单价。
- **实际回收**：已经到账的总额，含本金与利润，立即增加核心余额。例如成本 500、回款 650，填写回收 650。
- **本次结转成本**：只转走本次回款对应的原始投入数量，不再扣核心余额。可按多个成本币种填写。按钮可填入本条结算前的全部剩余成本。
- **更新占用总量**：项目在本条流水之后的占用总数；更新会覆盖此前快照，填 0 解锁。仍属于核心持仓，不扣总量。
- **更新剩余未结算估值**：本条流水之后尚未到账权益的估值。填 0 是确认无价值；勾选更新并留空是未知；不勾选则沿用此前快照。
- **额外手续费**：全部采用单列、额外扣减的口径。投入、回款、兑换和出入金字段应填写未含这笔额外费用的总额。不要将费用计入净额后再填一次。

实际投入和占用不得描述同一笔本金。同时填写时，表单要求确认它们是不同资金。部分或全部回款后，都必须更新剩余估值（可以填未知或 0），或结束项目，以免回款继续被算在估值中。**占用本金已在核心持仓，不要再次填入项目估值。**

一个项目可以有多次投入、分批回款、释放、估值和占用更新。仅作项目关联不会创建额外流水。非核心代币、NFT 的未变现权益放在项目估值中，换回核心币种后才记实际回款。

结束项目须明确结转全部剩余成本，包括亏损核销；确认结束后自动清空估值及占用。结束项目要追加流水时，选择“设为进行中 / 重新进行”。

投资流水可按项目、分类、状态、日期、币种、账户筛选，也可搜索名称、备注、账户，并按日期或项目名排序。编辑后全部重算；撤销前确认，原记录保留，可在“数据管理”恢复。存在依赖时会阻止无效修改，例如撤销已被后续结算使用的投入：应先撤销或修改相关结算，再改投入，不会静默生成错误成本。

### 2. 持仓

五种核心资产分别显示数量、占用、可用、当前单价及价值、项目估值、已结算和浮动盈亏。点击币种或数量，可查看余额流水、占用项目和估值来源。

“期初 / 调整”记录有日期和必填原因。两者都按**增量**入账；例如将 5 调整为 4，应填 −1。期初非负，调整可正可负；二者都不算项目盈利或净入金。

“手动兑换”一次保存换出和换入两边，以及额外手续费。兑换不算外部入金，也不会把换入资产全部计作利润。负余额或负可用数量会出现警示，并提供来源。

### 3. 法币出入金

选择 CNY 或 HKD，填写正数法币金额和对应 USD 总额，再选择方向。系统保存 `法币金额 ÷ USD 金额` 的实际成交汇率，报价方向始终为 **1 USD = 多少 CNY / HKD**。

入金增加 USD，出金减少 USD，单列手续费额外扣除 USD。净入金 = 入金 USD 总额 − 出金 USD 总额，费用另列，不将出入金当作收益。CNY、HKD 分别统计，不能直接相加。

若实际使用 USDT / USDC，另填实际支付数量。USD 等值由实际成交填写，系统保存 `USD 金额 / 实际稳定币数量` 所隐含的折算关系；不会自动假定稳定币永远等于 1 USD，也不额外建立稳定币持仓。同一外部资金只在此处录入，不要再记为投资回款。

### 4. 仪表盘

展示总资产、核心持仓、可用、占用、项目估值、历史已结算盈亏、当前浮动盈亏、净入金，数字可点击追溯。资产配比选择器有核心持仓、可用、占用、含项目估值四种口径；两个盈亏条形图以零线分隔亏损与盈利。

日期筛选只作用于**结算发生日期**和**出入金发生日期**。核心持仓、可用、占用、剩余估值和浮动盈亏始终是当前数据。未知成本或价格导致相关汇总显示“待补充”；负余额时不绘制误导性的配比图。

没有历史资产曲线，没有用今天的行情伪造历史回报。资产增长不等于项目盈利；核心币种自身价格变化仅改变当前价值。

### 5. 币价更新

BTC、ETH、BNB、SOL 使用 CoinGecko 公开 USD 行情，USD 固定为 1。可手动刷新，或在页面打开时按 1 / 2 / 5 / 10 / 15 / 30 / 60 分钟更新；默认个人账本 5 分钟，演示账本默认关闭自动更新。后台隐藏标签页不主动轮询。首次使用也可立即点“刷新行情”。

接口地址定义在 `src/prices.ts`。使用 `simple/price` 的固定币种 ID，并检查 `last_updated_at`。接口超时、限流、网络失败、非正数价格或失效时间均保留原价格，显示错误。超过刷新间隔两倍与 5 分钟中的较长时间标为过期。超过 30 分钟的接口数据不作为新价格接收。

手动备用价格带明显来源标记，时间记为保存时刻；下一次市场成功刷新会替换它。要保持手动价，可关闭自动更新。币价更新不改流水数量或历史价格快照。

来源：[CoinGecko API 文档](https://docs.coingecko.com/reference/simple-price)、[CoinGecko](https://www.coingecko.com/)。本版不需要密钥，不申请付费接口或云服务。公开接口可能限流、受区域网络和 CORS 影响，没有可用性保证；不会尝试以零价格代替失败。未来接入需要密钥的服务时，必须在自有服务端加代理，不能把密钥写进 `dist/`。

## 账务计算

完整字段与算法见 [数据结构及规则](docs/DATA_MODEL.md)。核心逻辑只在 `src/engine.ts` 实现，全部页面复用它。

```text
当前数量 = 期初 + 外部入金 − 外部出金 + 实际回收 − 实际投入
         − 额外手续费 + 余额调整 + 兑换净流入
可用数量 = 当前数量 − 占用数量
当前持仓价值 = 当前数量 × 当前 USD 价格
总资产 = 核心持仓价值 + 未结算项目估值的当前 USD 等值
历史结算盈亏 = 实际回款的历史 USD 等值 − 本次历史结转成本 − 结算费用
浮动盈亏 = 剩余估值的当前 USD 等值 − 剩余历史 USD 成本
```

同一项目、同一成本币种按 **FIFO（先进先出）** 分配成本。投入费用加入该批历史成本，随结转数量分摊；末次结转拿走全部尾差。结算费用当次计入盈亏。跨币种通过历史 USD 快照比较；同币种、同币种费用的结算另列币本位结果及今日折算值，后者明确不是历史盈亏。

金额以十进制字符串存储；账务用 18 位小数的 BigInt 定点运算，单笔绝对值最多 10^15 单位。乘除截断到 18 位，USD 显示用整数四舍五入至分；图表比例才使用浮点数。历史价格缺失使用 `null`，不会猜成 0。实际流水日期不能在未来。

## 备份、恢复与 CSV 迁移

个人账本：数据管理 → 下载加密备份。备份包括完整项目、流水（含撤销）、历史价格快照、当前价格、设置和修改追溯；用原口令在其他设备恢复即可。应用保存前完成校验，保存成功后才更新界面，并保留最近一次加密副本。

恢复流程：选择 JSON → 输入备份口令 → 解密和账务预览 → 确认替换。已解锁个人账本中恢复时，继续使用当前账本口令；从锁定状态恢复时，使用备份的口令。更新口令后请下载新备份；旧备份仍需旧口令。

若最近一次保存损坏，可在解锁弹窗选择“尝试上次自动副本”。自动副本只有一份，不能代替你保存在其他位置的备份。口令不存储、不上传，无找回后门。清理浏览器、卸载浏览器、无痕会话结束或变更域名/端口前，务必下载备份。

演示模式下载的 JSON 为明文虚构数据，只能恢复到演示模式；不能用它覆盖个人账本。示例文件在 `examples/demo-ledger.json`、`examples/demo-ledger.csv`。

CSV 导入流程：

1. 从飞书导出 UTF-8 CSV，或下载应用内模板。
2. 选择文件，自动匹配同名中英文列；展开“字段映射”调整。
3. 检查行预览、错误和重复数。类型为空时按投资流水，日期必须映射。
4. `本次结转成本` 支持 `USD:500;ETH:0.1`；历史币价不提供则标记待补充。估值填 `未知` 与填 `0` 意义不同。
5. 只有全部校验通过才能确认导入；错误须在原 CSV 修正后重新选择。预览显示前 200 行，所有行都会校验。
6. 同一 ID、相同内容跳过；同一 ID、不同内容报错，需在应用中编辑。没有 ID 时，按完整流水内容去重。已有项目按 ID 或唯一同名匹配；不会覆盖已有项目资料。关联项目用项目 ID。

CSV 可导出和导入五种流水及项目资料，含已撤销标记。**CSV 是明文，不包含完整审计历史、行情缓存或设置**，完整迁移请用加密备份。以 `= + @` 等开头的文本会做防公式转义，`CSV文本转义列` 保存可逆标记，请勿删除该列。详细列说明见 [CSV 指南](docs/CSV.md)。

## 私用联网部署与身份验证

- 本地预览默认只监听回环地址，不对外开放。
- 公开静态演示可直接托管 `dist/`，只展示内置虚构数据。个人数据通过浏览器的独立口令解锁，不上传到静态服务器。
- **联网私用必须使用 HTTPS 和服务端身份验证**。附带服务器的 `--auth` 对 HTML 和全部资源执行 HTTP Basic 身份验证。由部署环境的秘密配置提供 `LEDGER_USER` 与 `LEDGER_PASSWORD`（至少 12 字符，用户名不含冒号）。不要把这些值写进仓库或前端文件。

设置好服务端秘密后启动：

```sh
npm run serve:private
```

推荐在本机端口 4173 前配置自有 HTTPS 反向代理，并让外部流量只经 HTTPS 入口进入。确需绑定外部接口时，认证模式才允许：

```sh
npm run serve:private -- --host 0.0.0.0 --port 4173
```

此端口是 HTTP，必须限制为可信 HTTPS 代理可访问；不要直接暴露在公网。服务器拒绝缺少认证参数的外部监听，认证配置缺失会停止启动。测试验证未认证请求返回 401，正确认证返回 200，不能读取 `dist/` 外的文件。部署认证口令与账本加密口令是两个独立凭据。应用内“锁定”锁定账本，浏览器的 Basic 登录会话由浏览器管理。

静态托管本身无法添加服务端认证，私用时应选择宿主的身份访问控制或上述认证服务器。本交付不执行发布、配置域名、创建服务账号或购买云资源。

## 数据安全与使用限制

- 单人、单浏览器账本，无多设备云同步、共享账户或钱包读取。账户 / 地址只是标签。
- 个人数据使用 AES-256-GCM；口令经 PBKDF2-SHA256（310,000 次）派生密钥，每次保存使用随机 IV。刷新或 15 分钟无交互后需重新解锁。没有收集私钥、助记词或交易权限的功能。
- 不防已解锁设备上的恶意浏览器扩展、系统入侵或他人操作。请使用独立长口令和受信任浏览器。
- 保存受浏览器存储配额约束，个人账本及上次副本约占两份加密空间。空间不足会明确报错、保留原数据和未提交表单。多标签页写入冲突会阻止旧标签覆盖新账；锁定后重新解锁即可读到新版本。
- 只支持当前 schema 1。CSV 输入限制 10 MB，完整 JSON 备份限制 20 MB，结构最多 50,000 条流水 / 10,000 项目；这是解析保护上限，不是存储容量或性能保证。大量流水建议定期备份并按账期分账本迁移。
- 本版不管理核心币种买卖的税务成本、已实现交易差价或法币汇兑损益，不生成税表。项目收益与核心资产价格变化分开；不把总资产变化称为项目盈利。
- 当前价格、持仓和浮动盈亏不支持回溯到历史某日。历史成交价需手动提供；不自动回填历史行情。没有历史资产曲线。
- 自动行情仅在应用打开且标签可见时运行，不是后台定时服务。市场接口依赖外部可用性；记录、计算和备份不依赖它。
- 已验证 Chromium 手机/桌面模拟。WebKit 的可执行文件在提供的测试运行时不可用，Safari、真实 iPhone/Android、屏幕阅读器和浏览器原生 200% 缩放未实测；已测试 200% 根字体放大和小屏重排。
- 本地 Noto Sans SC 字体为界面用字子集，非内置的中文姓名、项目名使用系统字体回退；不请求远程字体。

- 生产构建、严格 TypeScript 类型检查。
- 账务、CSV、认证和加密自动化测试，含 250 组确定性随机部分结转守恒检查。
- Chromium 真实操作：建账、录入、持久保存、解锁、修改、撤销恢复、兑换、行情错误与重试、定时刷新、筛选、追溯、CSV 去重及加密恢复。

- Better Interface 六领域复核；taste@1 检查和 axe 检查；键盘焦点与弹窗退出。

浏览器测试需要额外提供 Playwright 与 Chromium（不属于应用运行依赖）：

node tests/browser.mjs /absolute/path/to/playwright/index.mjs
