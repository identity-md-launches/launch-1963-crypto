# CSV 字段与迁移

`src/csv.ts` 的 `FIELDS` 是准确列定义；支持中文列名或对应内部英文字段名。第一行是唯一表头，使用 UTF-8（可带 BOM）、英文逗号、双引号转义。备注可含逗号、引号、换行。日期必须是有效的 YYYY-MM-DD，数量使用英文小数点且不带千位分隔符。来源文件的英文逗号数量需先清理。

| 字段组 | CSV 列名 | 说明 |
|---|---|---|
| 通用 | 类型、流水ID、日期、账户、备注、创建时间、已撤销 | 类型：投资 / 出入金 / 兑换 / 期初 / 调整 / 项目。已撤销为 true / false；空为 false。缺 ID 自动生成。 |
| 项目 | 项目ID、项目名称、分类、关联项目ID、项目备注 | 分类缺失默认其他；项目ID优先，其次唯一同名匹配。已有项目资料不由重复导入覆盖。 |
| 投入 | 成本币种、成本数量、成本历史USD单价 | USD 单价恒为 1，其余缺价格为未知。币种缺失默认为 USD。 |
| 回收 | 回收币种、回收数量、结算历史USD单价 | 实际到账总额，不是净盈利。回款须同步更新估值或关闭项目。 |
| 结转 | 本次结转成本 | 按币种写原投入数量，如 `USD:500;ETH:0.1`，不能超过当时剩余成本。 |
| 投资费用 | 手续费币种、手续费数量、手续费历史USD单价、费用归属 | cost = 本次投入成本；settlement = 本次结算费用。全部单列额外扣减。 |
| 占用 | 占用币种、占用总数量 | 是覆盖快照；0 解锁；空数量不更新。切换币种替换原占用。 |
| 估值 | 估值币种、剩余估值 | 有币种而数量为空，或数量为“未知”，表示未知；0 表示已确认零。两列全空不更新。 |
| 状态 | 项目状态 | active / closed，空为保持。closed 必须同时结转完剩余本金。 |
| 法币 | 出入金方向、法币类型、法币金额、对应USD金额 | 方向 in / out 或 入金 / 出金；CNY / HKD；两列均须明确映射，不猜测方向或法币；金额正数。历史汇率自动按两个金额计算。 |
| 出入金费用 | 手续费数量 | 此类固定 USD 单列费用，非 USD 费用会被拒绝，须先折算；不由投资手续费规则处理。 |
| 实际支付 | 实际支付币种、实际支付数量 | USD / USDT / USDC，缺失为 USD。USD 必须与对应 USD 金额一致。 |
| 兑换 | 换出币种、换出数量、换入币种、换入数量、手续费币种、手续费数量 | 两边币种须不同；只记一条记录，系统同步变动两边余额。 |
| 期初 / 调整 | 调整币种、调整数量、调整原因 | 原因必填，调整可负，期初不可负，金额是增量。 |
| 导出保护 | CSV文本转义列 | 系统导出时自动填写的内部列名列表，标明为防电子表格公式执行而加前缀的文本列。保留此列可以无损重新导入。 |

最小投资示例（虚构）：

```csv
类型,日期,项目名称,分类,成本币种,成本数量,成本历史USD单价,估值币种,剩余估值
投资,2026-01-01,虚构项目,生态投资,USD,400,1,USD,450
```

随后全部结算：

```csv
类型,日期,项目名称,回收币种,回收数量,结算历史USD单价,本次结转成本,项目状态
投资,2026-01-02,虚构项目,USD,500,1,USD:400,closed
```

若成本尚未导入，第二个示例会因超额结转而报错。新增币种价格不会修复历史快照，需编辑原投资记录补充当时单价。

预览时“新增 / 重复”是解析后的流水计数，项目资料会单独显示“项目资料”。所有错误都会阻止批次提交，没有悄悄跳过坏数据。预览显示至多 200 行和 100 项错误，但校验覆盖全部输入。

提供并映射流水 ID 时，只按 ID 判断重复：相同 ID、相同内容跳过；相同 ID、不同内容报错；不同 ID 的独立交易全部保留，即使日期、账户、金额、备注完全一致。同一文件再次导入不会增加流水。

只有未提供流水 ID（或未映射该列）的行才按完整内容去重，指纹不包含自动生成的 ID 和创建时间。若这样的源数据包含两笔所有内容完全相同的真实交易，请为每笔添加不同且稳定的流水 ID，或在备注加入唯一交易序号。CSV 不能自动判断两种不同类型流水是否描述同一外部资金，请在迁移前统一口径。
